# GeraldTMs HTTP Server(s)

This repository was made as a learning exercise, and contains a http server impl in (almost) every language I know/ want to learn.

The http servers are not feature complete, not secure, and should not be used outside an isolated environment and should only be used for learning purposes.

## Completed Languages
- [Python](https://github.com/GeraldTM/http/tree/python)

## Features
- GET request handling: 
  - access local files from the browser through the use of  GET requests
- POST request handling:
  - Log all post request data for later use
- Error status codes and edge case handling
  - Log issues while alerting the client and keeping the server operational
